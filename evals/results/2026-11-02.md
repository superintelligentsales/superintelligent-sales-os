## How to read a revert

A round is kept only if the total rises, the targeted test passes, and nothing that passed now fails. The grader is a model, so a test can pass on one scoring and fail on the next with no change to the skill. When a round was reverted because an untouched test flipped, the loop re-scored the unchanged skill once and counted a test as passing only if it passed both times.
