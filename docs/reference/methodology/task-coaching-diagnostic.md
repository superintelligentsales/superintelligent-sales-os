# TASK Coaching Diagnostic

> Methodology reference. Loaded by `manager/one-on-one-prep`, `manager/development-plan-generator`, `manager/friday-skill-workshop`, and any Manager Layer skill that produces coaching recommendations.

## When to use this

Before any coaching conversation, performance review, or development plan. TASK is the diagnostic that runs *upstream* of coaching — it tells the manager what to coach to. A coaching session without a TASK diagnosis is a conversation, not coaching.

## The core thesis

Most managers coach the wrong thing. They see a number that's off — pipeline is short, win rate is down, deals are slipping — and they jump straight to the rep with feedback. The feedback misses because the manager hasn't separated the *outcome* from the *behavior that produces the outcome*.

TASK forces that separation. It descends from outcome to root cause in four steps, and each step is independently coachable:

```
T — Target Result          (the outcome you're driving)
↓
A — Activities             (the key sales moments that produce the outcome)
↓
S — Skill                  (how those activities are performed)
↓
K — Knowledge              (what the rep needs to know to perform the skill)
```

Read top-to-bottom, this is the manager's diagnostic flow. Read bottom-to-top, this is how performance is built: knowledge enables skill, skill enables activity, activity produces results.

## The four elements

### T — Target Result

The lagging outcome the manager is driving, paired with a **specific drill-down metric**. "More pipeline" is mush; "600K pipeline per rep per quarter" is operable. If the target can't be reduced to a number, it isn't a target — it's a wish.

Common targets at the rep level:

| Category | Example targets | Drill-down metric |
|---|---|---|
| Pipeline | More pipeline | $600K pipeline / rep / quarter |
| Win rates | Higher conversion | Win rate at Solution stage 35% → 45% |
| Contract value | Larger deals | ACV $35K → $50K |
| Sales cycle | Faster close | Cycle days 110 → 85 |

### A — Activities (Key Sales Moments)

The leading inputs that produce the target. **This is where TASK integrates directly with the Seven Key Moments.** Every activity a manager coaches to is one of the seven moments — Prospecting & Qualification, Discovery, Demo, Solutioning, Business Case, Proposal & Negotiation, Close & Handoff — or a precursor activity (research, account planning, cadence calls, social selling) that feeds into a moment.

When TASK lands on Activities, the next question is always: *which of the seven moments does this activity belong to, and what does "good" look like at that moment?* The Rep Layer methodology answers that question.

### S — Skill (Practiced and Quality)

How the activity is performed. The two qualifiers matter:

- **Practiced** — skill is built through deliberate repetition (the Champion's Code Culture of Practice). A manager coaching to skill without scheduling practice is hoping, not coaching.
- **Quality** — skill has a quality gradient. "Made the calls" is activity. "Ran the calls with strong objection handling, sharp value prop, and personalization" is skill.

For a single activity (e.g., outbound calls), the underlying skills typically include: objection handling, pitch delivery, value-prop articulation, personalization, pre-call research.

### K — Knowledge (Taught, Referenced, or Check-Listed)

What the rep needs to know to perform the skill. Knowledge has three modes of transfer:

- **Taught** — explicit instruction in workshops, 1:1s, onboarding
- **Referenced** — captured in playbooks, battle cards, case studies the rep accesses on demand
- **Check-listed** — embedded in pre-call plans, discovery scripts, demo runbooks the rep walks through every time

For an outbound call activity, the underlying knowledge typically includes: industry context (business model, key challenges, competitors), value proposition (industry/persona-specific differentiators, competitive positioning).

## Worked example: "More Pipeline" target

| Element | Content |
|---|---|
| **T** — Target Result | More pipeline → $600K pipeline / rep |
| **A** — Activities | Calls, emails, LinkedIn engagement, social selling, prospecting cadences |
| **S** — Skill | Calls — objection handling, pitch delivery, value-prop articulation, personalization, pre-call research |
| **K** — Knowledge | Industry — business model, key challenges, competitors. Value Prop — specific to industry/persona, differentiators, competition |

The diagnostic question at each level:

1. *Is the target clear and measured?* If no, fix that first
2. *Are the activities being run at sufficient volume?* If no, the gap is activity, not skill
3. *Are the activities being run with quality?* If no, the gap is skill — schedule practice
4. *Does the rep know what they need to know?* If no, the gap is knowledge — teach, reference, or check-list

## TASK & Leading Indicators: Canonical patterns

The worked example covers one specific target. The table below maps the four most common lagging business results managers face — each one fully decomposed into Target → Activities (leading indicators) → Knowledge/Skill investments.

| Sales Business Result (Lagging) | Target Result | Activities (Leading Indicators) | Knowledge / Skill Coaching |
|---|---|---|---|
| **Low Quota Attainment** | Pipeline volume sufficient for coverage | Territory penetration, account tiering and prioritization, email and call volume, # of opps in pipeline, account and prospect research | Prospecting email and calling best practices, storytelling, targeted messaging |
| **Long Sales Cycle** | Next steps scheduled, # of Mutual Action Plans created | Creating account maps, engaging champions and decision-makers, dealing with blockers and technical buyers, scheduling next steps | Account map discipline, champion development, MAP construction |
| **Low Win Rate** | # of impact questions asked, emotional + rational impacts tracked per stakeholder, # of multi-threaded deals | Discovery call best practices, value selling, ROI calculation, MAP creation | Discovery skill, value-selling skill, ROI articulation |
| **Low Contract Value** | Deal size at each stage, product bundling, procurement conversation quality, discounting discipline, senior buyer engagement | Negotiations, value selling, ROI calculation, storytelling, MAP creation | Negotiation skill, value-selling skill, executive engagement |

The pattern is the same in every row: *a lagging business result decomposes into a measurable target, which decomposes into specific leading-indicator activities, which decompose into the skills and knowledge that produce them.* When a manager looks at a struggling rep, this table is the first place to land — it converts a vague "the numbers are off" into a specific coaching plan.

For deeper per-metric diagnostic guidance — including branching coaching paths (e.g., "Win rate is low: is this a qualification issue or an execution issue?") — see `managing-to-metrics-library.md`.

## Diagnostic logic: "If this, then that"

Standard diagnostic patterns save managers from reinventing the wheel. When a metric is off, this is the first-pass check:

| Symptom | Likely TASK level | First investigation |
|---|---|---|
| Connect rate is low | Activity quality (Skill) | Time of day, list quality, opening hook |
| Conversion (meeting → opp) is low | Skill | Opening framing, value-prop delivery in first 5 minutes |
| Progression (early-stage → mid) is low | Skill + Knowledge | Discovery quality, SPICED completeness, industry knowledge |
| Close rate is low | Skill + Knowledge | Critical event identification, decision committee mapping |
| Volume is low everywhere | Activity (not skill) | Calendar audit, time blocking, prospecting cadence |
| Performance varies by deal type | Knowledge | Industry/persona knowledge gaps |

## How TASK feeds the coaching workflow

The diagnostic produces coaching artifacts at each level:

- **Target → Drill-down metric** → goes on the rep's scorecard, reviewed in 1:1
- **Activity gap** → goes into activity coaching (volume, cadence, calendar discipline)
- **Skill gap** → goes into skill workshop or 1:1 role play (Friday skill workshop or 1:1 coaching block)
- **Knowledge gap** → goes into the development plan (what to teach, reference, or check-list)

A complete TASK diagnosis produces a complete coaching plan. Skipping any level produces a partial plan that misses by definition.

## Why TASK over alternatives

TASK replaces REKS (Results / Efforts / Knowledge / Skills) in the Dana methodology. Three reasons:

1. **Activities = Key Sales Moments** is an explicit integration with the Rep Layer. REKS's "Efforts" had no such bridge.
2. **The drill-down metric** forces target specificity. REKS's "Results" was vaguer.
3. **The causal flow** (Target → Activity → Skill → Knowledge) matches how managers actually diagnose. REKS placed knowledge before skills, which is backwards — skill is what gets practiced, knowledge is what supports the skill.
