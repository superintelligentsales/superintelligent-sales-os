# Revenue Math

How to price a conversion gap using only the user's numbers and cited benchmarks.

## Contents
- Value of one point
- Gap value
- Worked example
- Rules

---

## Value of one point

For any stage, one extra percentage point of conversion means more deals flow through every later stage.

**Value of one point** = deals entering the stage x 1% x (rate of every later stage, multiplied together) x average deal value

For win rate (Opportunity to Won), there are no later stages, so:

**Value of one win-rate point** = opportunities x 1% x average deal value

## Gap value

**Gap value** = (low end of the benchmark range minus the user's rate, in points) x value of one point

Use the low end of the range so the figure is conservative. If the user's rate is inside the range, there is no gap to price at that stage. When there is no cited benchmark, price the gap to the user's own target or best recent period only if the user gave one, and label it that way.

**What success is worth** in the deep dive = the gap value if the gap closes halfway. Present it as a target, not a forecast.

## Worked example

Fictional numbers. One quarter: 450 MQLs, 54 SQLs, 30 opportunities, 6 won, average deal $40,000.

- MQL to SQL = 54 / 450 = 12%. SQL to Opportunity = 30 / 54 = 56%. Win rate = 6 / 30 = 20%.
- Value of one MQL-to-SQL point = 450 x 1% x 56% x 20% x $40,000 = about $20,160 a quarter.
- If the cited range's low end were 15%, the gap = 3 points, so gap value = 3 x $20,160 = about $60,500 a quarter, or about $242,000 a year.
- Value of one win-rate point = 30 x 1% x $40,000 = $12,000 a quarter.

## Rules

- Show each formula with the user's numbers, once.
- State the period every time (month, quarter, year). Annualize only by multiplying a stable quarterly figure by four, and say so.
- Round to two significant figures in the summary; keep the exact figure in the table.
- Never invent a deal value, volume, or rate. If one is missing, say which number would complete the math.
- Dollar impact of a lead-source or segment issue: (better rate minus current rate) x the volume that could move x later rates x deal value, using only figures the user gave.
