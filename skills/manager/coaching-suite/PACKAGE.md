# Coaching Suite

Build status: the TASK diagnostic is the first draft sub-skill. Other catalogued
coaching skills are not implemented by this package. This file records the shared
principles; it does not claim the whole suite is installed or accepted.

## Operating Principles

- **Beneath metrics are behaviors.** Coach activities and skills after establishing the evidence.
- **Diagnose in groups, treat in 1:1s.** Keep individual development private.
- **Verified, not vibes.** Cite a quote, timestamp, or record; omit unsupported claims.
- **Customization is the moat, not the methodology.** Apply the user's private context.

These principles come from the build handoff and the existing management methodology.
They live here once; each sub-skill applies them without duplicating this section.
