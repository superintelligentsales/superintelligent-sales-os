## Coaching Skills

| Skill | Purpose |
|---|---|
| task-diagnostic | Investigate target, activities, skill and knowledge with evidence. |
| development-plan-generator | Turn an accepted diagnosis into one development plan. |
| five-step-coaching-conversation | Prepare or guide a manager–rep coaching exchange. |
| ai-roleplay-partner | Rehearse a buyer situation and debrief practice. |
| action-tracking | Review accepted commitments against returned evidence. |
| coaching-orchestrator | Propose one justified next coaching action per relevant rep. |

The sequence is Diagnose → Plan → Practice → Reinforce according to the rep's
current state. A routing recommendation does not automatically execute that sequence.
Populate context in a private working copy, discover actual runtime capabilities,
and retain each skill's readiness and permission gates.

## Operating Principles

- **Beneath metrics are behaviors.** Coach activities and skills after establishing the evidence.
- **Diagnose in groups, treat in 1:1s.** Keep individual development private.
- **Verified, not vibes.** Cite a quote, timestamp, or record; omit unsupported claims.
- **Customization is the moat, not the methodology.** Apply the user's private context.

These principles come from the build handoff and the existing management methodology.
They live here once; each sub-skill applies them without duplicating this section.
